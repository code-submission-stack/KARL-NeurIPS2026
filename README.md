## Overview

**KARL** is the first hybrid Residual Graph Kolmogorov-Arnold Network (KAN) integrated into
an off-policy deep reinforcement learning agent for combinatorial optimisation over multiplex
networks. KARL solves the **multiplex network dismantling problem** — identifying the
minimum-cost node-removal sequence that fragments the Largest Mutually Connected Component
(LMCC) into non-extensive subgraphs — under both unit cost and degree cost regimes.

KARL is trained exclusively on small synthetic multiplex graphs (30–50 nodes) generated by
the Geometric Multiplex Model (GMM), and generalises zero-shot to real-world multiplex
networks spanning three orders of magnitude (up to 56,562 nodes).

### Key Results

| Metric | KARL vs. MultiDismantler | KARL vs. all baselines |
|---|---|---|
| Avg. AUDC reduction (unit cost) | **−21.8%** | Best on all 6 datasets |
| Avg. C* reduction (unit cost) | **−12.0%** | Best on all 6 datasets |
| Avg. AUDC reduction (degree cost) | **−24.9%** | Best on 5/6 datasets |
| Zero-shot generalisation | ✓ 30→56k nodes | Trained on N∈[30,50] only |

## Architecture

KARL processes each graph state through three sequential KAN-parameterised stages:

```
Input (node degree features)
        │
        ▼
┌─────────────────────────────────────┐
│  Stage 1: Residual B-Spline KAN     │  ← Intra-layer message passing
│  Encoder  (×3 iterations)           │    with learnable residual MLP branch
│  KANneigh ∥ KANself → KANout        │    (αres = 0.5, G=10, k=3)
└─────────────────────────────────────┘
        │
        ▼
┌─────────────────────────────────────┐
│  Stage 2: KANformer                 │  ← Cross-layer fusion via
│  Multi-Head KAN Attention           │    fully KAN-parameterised
│  Q/K/V projections (B-Spline)       │    Q, K, V, O projections
└─────────────────────────────────────┘
        │
        ▼
┌─────────────────────────────────────┐
│  Stage 3: Chebyshev-KAN Q-Head      │  ← Orthogonal polynomial basis
│  ChebyKANhidden (d→32, K=4)         │    for stable TD regression
│  ChebyKANfinal  (36→1, K=4)         │
└─────────────────────────────────────┘
        │
        ▼
   Q(St, av) — action-value per node
```

**Why KANs over MLPs?**
Standard MLPs apply a single global affine map per input coordinate, limiting their capacity
to represent the sharp, non-smooth per-node vulnerability functions that govern cascading
failures in scale-free multiplex networks. KANs place learnable univariate B-spline functions
directly on network edges, adapting the functional form — not just the coefficients — to each
input coordinate. KARL's B-spline encoder is 14× more expressive per layer than an equivalent
linear map, while the orthogonal Chebyshev Q-head prevents the Runge-type boundary
oscillations that affect fixed-grid B-splines under non-stationary TD targets.


## Data

### Synthetic graphs (training)
Generated on-the-fly by `GMM.py` using the Geometric Multiplex Model with:
- Power-law exponent γ = 2.5
- Mean degree k̄ ∈ [2, 10] (randomly sampled per graph)
- Inter-layer correlation g = 0.5 (unit cost) / g ~ Unif[0,1] (degree cost)
- Node count N ∈ [30, 50]

### Real-world benchmarks (evaluation)
Place `.edges` files in `data/multiplex_edges/`:

| Dataset | N | Layers | Domain |
|---|---|---|---|
| C. elegans Connectome | 279 | 2–3 | Neural |
| FAO Multiplex Trade | 214 | 3–24 | Economic |
| Facebook-Twitter | 1,043 | 1–2 | Social |
| Sacchpomb Genetic | 4,092 | 4–6 | Biological |
| Homo Sapiens Genetic | 18,222 | 1–2 | Biological |
| Sanremo2016 | 56,562 | 1–2 | Social |

All datasets are publicly available from the
[Manlio De Domenico multiplex repository](http://mlg.ucd.ie/datasets/multiplex.html).

## Training

### Unit cost
```bash
python train.py
```

### Degree cost
```bash
# Ensure karl_env.py uses the degree-cost reward (getReward with graph.weights)
# and graph.py has cal_degree() populating self.weights
python train.py
```

Training hyperparameters (set inside `karl_agent.py`):

| Hyperparameter | Value |
|---|---|
| Episodes | 20,000 |
| N-step returns | 5 |
| Discount γ | 0.99 |
| ε-greedy decay | 1.0 → 0.05 |
| Replay memory | 50,000 |
| Batch size | 64 |
| Learning rate (linear params) | 1 × 10⁻⁴ |
| Learning rate (spline params) | 1 × 10⁻³ |
| B-Spline grid G | 10 |
| B-Spline order k | 3 |
| Chebyshev degree K | 4 |
| Residual scalar αres | 0.5 (learnable) |
| Target network update | every 1,000 steps |
| Laplacian regulariser λ | 0.001 |

Models are saved to `models/KARL_GMM_N30-50_unit/` or `models/KARL_GMM_N30-50_degree/`.

## Evaluation

```bash
python evaluate.py -o results/KARL_unit/
```

Edit the dataset list and model path inside `evaluate.py`:
```python
model_file_ckpt = 'KARL_GMM_N30-50_unit/karl_ep20000_best.ckpt'
data_test_name  = ['fao_trade_multiplex', 'celegans_connectome_multiplex', ...]
```

Outputs per dataset (written to `results/`):
- `NormalizedLMCC_<dataset>.txt` — dismantling trajectory (y-axis values)
- `Cost_<dataset>.txt` — cumulative cost at each step (x-axis values)
- `time&audc_<dataset>.csv` — runtime and AUDC score

## Computational Cost

| Metric | KARL | MultiDismantler | Ratio |
|---|---|---|---|
| Parameters | 322,326 | 31,205 | 10.3× |
| Training step time | 315 ± 66 ms | 166 ± 56 ms | 1.9× |
| Inference (geom. mean) | 268 ms/step | 139 ms/step | 1.93× |
| Peak GPU memory (geom. mean) | ~1,090 MB | ~270 MB | 4.2× |
| Training wall time (A100) | ~4 h | ~2 h | ~2× |

KARL's overhead is driven by B-spline basis materialisation in `EfficientKANLayer`
and the fully KAN-parameterised KANformer attention projections.
These costs buy a **21.8% AUDC reduction** over MultiDismantler — a Pareto-optimal
operating point among all evaluated dismantling methods.
